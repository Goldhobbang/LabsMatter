# ADR-0003: Physical Units

**Status:** Accepted
**Date:** 2026-11-04
**Owner:** A1

## Decision

SI-derived units: meters (length), kilograms (mass), seconds (time), Kelvin (temperature), Pascals (pressure). Cell size default 0.01 m.

## Consequences

- Consistent with physics/chemistry literature.
- Easy validation against real-world values.
