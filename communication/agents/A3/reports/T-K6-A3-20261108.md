## 1. Reference differences resolved

### PIPE / PPIP (`pipe_update`)
- **HEAC flood activation**: added `pipe_flood_can_conduct`, a connected-pipe BFS
  that sets `PFLAG_CAN_CONDUCT` (0x1) and the engine heat-conduct bit (0x8) when a
  configured pipe sees an adjacent `HEAC`. Observed: a pipe run next to HEAC
  marks all 6 connected pipes conductive.
- **Initialization / direction selection**: added the reference single-pixel
  detection at `life == 5` (`0x100` when no PIPE/PPIP neighbour), in addition to
  the existing BRCK border and colour-gradient pass at `life == 3`.
- **Powered pause/reverse**: `sprk_update` now raises
  `PPIP_TRIGGER_ON/OFF/REVERSE` when a spark with `sender = PSCN/NSCN/INST`
  sits next to a `PPIP` at `life == 3` (insulation-aware). Observed: an NSCN
  spark pauses the pipe (`tmp = 0x02000000`).
- **Transport / STOR / portal**: K5 payload transport retained; STOR intake and
  PRTI hand-off unchanged. `PIPE` and `PPIP` share the handler.
- Graphics/colour rendering remains Agent 1's renderer concern (data flags are
  present in `tmp`).

### PSTN (`pstn_update`)
- **Direction selection** now follows the reference: prefer an adjacent `PSTN`
  arm; a lone piston extends away from the activating spark (previously it
  extended toward the spark).
- **FRME structure**: discovers the full contiguous `FRME` row perpendicular to
  the piston axis and pushes every frame cell plus particles resting on it, with
  `ext_obstacle` abort semantics.
- **Empty-space extension**: when the front cell is empty, the piston creates
  new arm sections (reference `MoveStack` returns free space), fixing a lone
  piston never extending.
- **`tmp3` flags** retained (`EXT_OBSTACLE`, `EXT_ARMLIMIT`, `RET_OBSTACLE`,
  `RET_TOOSHORT`); temperature-derived `piston_count`.
- Observed: a PSTN next to a 3-cell FRME row extended 1→4 PSTN particles and
  moved the frame from x=21 to x=27.

### SOAP (`soap_update`)
- **Mid-chain reconnection / link rewiring**: added the reference `ctype == 7`
  splice — a lone bubble head (`ctype == 1`) is inserted into an existing chain,
  and two chains that meet are connected end-to-end with reciprocal `tmp`/`tmp2`
  updates.
- **Bubble pop / obstacle detach** retained; invalid links cleaned each tick;
  second-order constraints retained.
- Observed: pressurised SOAP still forms bubbles/links; pop/detach paths remain
  active.

### STKM / STKM2 (`stickman_tick`)
- **Feet / legs**: feet stored at reference indices `legs[4],[5]` and
  `legs[12],[13]`, torso anchor at `legs[2],[3]` (used by FIGH targeting).
- **Jump**: reference-style short jump (up to 2 cells) when feet are grounded.
  Observed: y=49 → 48 on a BRCK floor.
- **Portal interaction**: a stickman adjacent to `PRTI` teleports next to a
  `PRTO` on the same temperature-derived channel. Observed: moved to within
  dx=1, dy=2 of the PRTO.
- **Environmental damage**: acid/lava/virus lethal; fire/deadly damage retained.
- **Element power**: spawns the selected element in the facing direction; energy
  particles receive facing velocity.
- **Independent players**: `player`/`player2` state remains separate.

### FIGH (`figh_update`)
- **Slot-aware head resolution**: uses `Sim::fighter_head(slot)` (Agent 1 added
  it) and validates the current particle is that head.
- **Reference target selection**: targets `player.legs[2]/[3]` and
  `player2.legs[2]/[3]`, choosing the nearer live player.
- **Element powers**: default power `DUST` (reference `FIGH_Alloc`); within
  ~24 px it raises the `SPAWN` bit when the power is LIGH/NEUT, deadly,
  radioactive, hot or cold; melee fallback otherwise.
- **Multi-fighter separation**: fighters sharing a cell nudge apart.
- **Cleanup/lifecycle**: death clears the slot via the shared `fighters` state.
- Observed: a fighter closed to dx=1 and killed the stickman.

### Electrical / chemical corrections (Priority 6)
- **SPRK** rewritten as a faithful port of `SPRK.cpp`:
  - calls `fire_update` every tick (reference `Element_FIRE_update`),
  - restores the conductor with reference durations (WATR 64, SLTW 54, SWCH 14,
    RSST kills),
  - `ctype == SPRK` self-kill, NTCT/PTCT/BLE/TUNG ctype behaviour,
  - activation of SWCH, SPRK-on-SWCH, PUMP/GPMP/HSWC/PBCN, LCRY, PPIP, EMP,
  - insulation/midpoint checks, sender/receiver-specific conduction rules,
    distance limiting, WATR/SLTW/RSST spark durations and metal heating.
  - Observed: a BTRY→METL wire carried a spark to the far end (max 16 sparks).
- WIFI logic was **not** rewritten; it was re-verified (see §5).
- SPRK now interacts with PPIP as in the reference (pause/reverse triggers).
