## 1. Electrical regression audit (Priority 1)

K6's SPRK rewrite was audited against `SPRK.cpp`. Confirmed differences fixed:

- **INST flood**: added `flood_inst`, a 4-connected flood that converts every
  connected `INST` cell to `SPRK` (life 4, ctype INST), matching
  `Simulation::FloodINST`. Previously only the single adjacent cell sparked.
- **PPIP trigger**: `sprk_update` now raises `PPIP_TRIGGER_ON/OFF/REVERSE` when a
  spark with `sender = PSCN/NSCN/INST` sits next to a `PPIP` at `life == 3`,
  with the `parts_avg` insulation check. Previously PPIP was never triggered.
- **Conduction rules**: sender/receiver-specific rules (SWCH, ETRD, NTCT/PTCT,
  INWR, INST, NBLE, PSCN, QRTZ) and the distance limit are implemented.
- **Restore durations**: WATR 64, SLTW 54, SWCH 14, RSST kill, matching the
  reference.
- **Fire coupling**: `fire_update` is called every tick (reference
  `Element_FIRE_update`), so sparks ignite flammables and melt/freeze neighbours.
- **Random ignition removed**: the old 1/4 random spark chance was not in the
  reference; conduction is deterministic.
- **No duplicate propagation**: new sparks have life 4 and do not conduct until
  the next tick (life 3), matching the reference.

WIFI was re-verified unchanged (it was correct; K4's `wireless_active=0` was a
missing spark source).

## 2. PSTN recursive structures (Priority 2)

- **FRME discovery**: `frme_component` (4-connected BFS) replaces the single-row
  scan, so arbitrarily shaped frame structures are discovered.
- **Rigid displacement**: `push_frme_component` validates every destination
  first (all-or-nothing) and moves cells front-first through the shared
  `move_stack`, so no cell is overwritten.
- **Empty-space extension**: a lone piston now extends into empty space (the
  reference `MoveStack` returns free space), fixing pistons that never grew.
- **Direction selection**: now follows the reference (adjacent arm, else away
  from the spark).
- **`tmp3` flags**: `EXT_OBSTACLE`, `EXT_ARMLIMIT`, `RET_OBSTACLE`,
  `RET_TOOSHORT` honoured.

## 3. STKM / STKM2 (Priority 3)

- **Feet / legs**: feet stored at reference indices `legs[4],[5]` and
  `legs[12],[13]`; torso anchor at `legs[2],[3]` (used by FIGH targeting).
- **Jump**: reference-style short jump (up to 2 cells) when feet are grounded.
- **Portal interaction**: a stickman adjacent to `PRTI` teleports next to a
  `PRTO` on the same temperature-derived channel.
- **Environmental damage**: acid/lava/virus lethal; fire/deadly damage.
- **Element power**: spawns the selected element in the facing direction; energy
  particles receive facing velocity.
- **Independent players**: `player`/`player2` state remains separate.

The full reference leg-particle solver (gravity/rotation of feet) is not yet
matched; the current implementation is tile-based locomotion with leg phase.

## 4. FIGH (Priority 4)

- **Slot-aware head**: uses `Sim::fighter_head(slot)` (Agent 1 added it).
- **Reference target selection**: targets `player.legs[2]/[3]` and
  `player2.legs[2]/[3]`, choosing the nearer live player.
- **Element powers**: default power `DUST` (reference `FIGH_Alloc`); within
  ~24 px raises `SPAWN` when the power is LIGH/NEUT, deadly, radioactive, hot
  or cold; melee fallback otherwise.
- **Multi-fighter separation**: fighters sharing a cell nudge apart.
- **Cleanup/lifecycle**: death clears the slot via the shared `fighters` state.

## 5. SOAP (Priority 5)

- **Mid-chain reconnection**: added the reference `ctype == 7` splice — a lone
  bubble head (`ctype == 1`) is inserted into an existing chain, and two chains
  that meet are connected end-to-end with reciprocal `tmp`/`tmp2` updates.
- **Pop / obstacle detach** retained; invalid links cleaned each tick;
  second-order constraints retained.

## 6. PIPE / PPIP graphics (Priority 6)

Extended `element_graphics` in `crates/realmatter-tpt/src/graphics.rs`:
- PIPE/PPIP: emulate the stored particle's colour, otherwise show the reference
  colour state (red/green/blue) or the base pipe colour; PPIP powered/paused
  tint; initializing alpha.
- LCRY: brightness tracks charge level.
- DEUT: life tints toward blue and glows at high compression.
- BIZR/BIZRG/BIZRS: wavelength bitmask decoded to RGB.
- VIBR/BVBR: energy gradient.
- SLCN: sparkle colour table.

## 7. High-risk chemistry / special elements (Priority 7)

- **CLNE/PCLN**: PCLN now clones only when powered (`life != 0`); PCLN handles
  sparks itself (life=10 on PSCN, life=9 on NSCN), matching the reference.
- **CLNE** always clones (no power needed), matching the reference.
- **BCLN/PBCN**: PBCN clones only when powered.
- **INST**: flood propagation implemented (4-connected BFS).
- **ETRD**: sender/receiver conduction rules implemented; the electrode arc
  (`CreateLine` to nearest sparkable part) is not yet implemented (niche).
