- `cargo build` (workspace): **FAILED** — `realmatter-core` does not compile.
  - Circular type alias: `SimResult<T> = Result<T, SimError>` and
    `Result<T> = SimResult<T>` (error.rs) → E0391.
  - Duplicate definitions: `MaterialState`, `MaterialProps` redefined as type
    aliases to non-existent `Material`/`Phase` (material.rs) → E0428.
  - `lib.rs` re-exports `Material`, `Phase` which are not defined → E0432.
  - `lib.rs` re-exports `World` from `world` which has no `World` type → E0432.

  transitively. Persist additionally has duplicate re-exports and references to
  `realmatter_core::Material`/`World`/`Persistence`/`SimError`/`SimResult` that
  do not exist in the current core.
