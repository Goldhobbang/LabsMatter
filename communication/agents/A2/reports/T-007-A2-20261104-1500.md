## WASM exports implemented

All in `crates/realmatter-wasm/src/lib.rs` (added `realmatter-persist` dep):
- `init(width, height) -> Result<(), JsValue>` (validates config)
- `step(dt: f64)` (powder + liquid movement, finalize, re-render)
- `set_cell(x, y, material) -> bool`, `get_cell_material(x, y) -> u16`,
  `get_cell_temperature(x, y) -> f32`
- `world_width() -> u32`, `world_height() -> u32`, `reset() -> bool`
- `render_buffer_ptr() -> *const u8`, `render_buffer_len() -> usize`
  (RGBA8 per cell, row-major y-outer/x-inner; 4 bytes/cell)
- `save_blob() -> Vec<u8>`, `load_blob(bytes) -> bool` (persist v1)
- Built-in materials: 0 empty, 1 wall (FIXED), 2 sand (powder), 3 water (liquid)
